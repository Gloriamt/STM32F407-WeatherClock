# 实物展示素材占位

仓库首页目前使用 `board-placeholder.svg`。它只是明确标注的占位图，没有展示任何虚构实机画面。

## 补充运行照片

1. 拍摄开发板运行照片：能看清时间、室内温湿度、上海天气和 Wi-Fi 状态，尽量包含实际硬件。
2. 遮蔽照片中的 Wi-Fi 密码、API 密钥、个人信息，SSID 如需公开也先确认无敏感信息。
3. 将照片保存为 `docs/media/board-running.jpg`（也可用 PNG），按阅读尺寸压缩。
4. 将根 README 的占位图片行替换为：

```markdown
![STM32F407 天气时钟实机运行](docs/media/board-running.jpg)
```

5. 将展示表中的“待补充”更新为照片说明。占位图不再使用后可以删除。

## 补充演示视频

建议录制正常显示、断网后的 `-----` 和 `HH:MM更新`、重新连接及天气刷新。录制时避免复位开发板，让观看者看到连续恢复过程。

视频先不提交到 Git。可上传到 GitHub 附件或视频平台，然后将根 README 展示表的视频状态替换为链接：

```markdown
[观看断网与重连演示](替换为真实视频链接)
```

以上只是复制用的示例，首页当前没有指向不存在的视频。添加素材后通过独立分支和 PR 更新说明即可。
